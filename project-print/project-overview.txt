Solar Potential Predictor: Research Project Overview
===================================================

Research framing
----------------
Solar Potential Predictor is a reproducible applied machine-learning study of
tract-level rooftop solar potential. It asks whether annual solar generation and
related aggregate outcomes can be estimated from geographic location,
qualified-roof and coverage measures, and directional sunlight features in a
cleaned Project Sunroof-style census-tract dataset.

The repository's principal contribution is the documented analytical workflow:
a supplied raw dataset, a rebuildable ETL process, explicit feature engineering,
seeded regression experiments, and synthetic regression tests. It is not a
property-level assessment, a financial quote, or a production solar-design tool.

Research question
-----------------
Primary question:

  Can tract-level annual rooftop solar generation potential be estimated from
  geospatial, roof-related, and directional sunlight features?

The code also enables exploratory questions about feature importance within the
Random Forest and comparison with a Linear Regression baseline for their shared
generation and carbon outcomes. Those questions are descriptive and predictive;
they do not establish causal effects or individual-rooftop accuracy.

Data and analytical representation
----------------------------------
The supplied raw CSV contains 48,722 census-tract rows and 31 columns. The ETL
pipeline removes rows containing any missing raw value, then retains 13 fields.
The resulting clean CSV and SQLite table contain 48,664 complete tract records.

The retained fields cover:
- tract-center latitude and longitude;
- qualified-roof count, covered percentage, and qualified percentage;
- annual sunlight measures for north, east, south, and west orientations;
- annual sunlight yield per kW threshold average; and
- annual sunlight total, carbon-offset potential, and total capacity.

The unit of analysis is the tract. These values describe area-level aggregates;
they are not measurements for a single property.

Modeling workflow
-----------------
The primary experiment is a 200-tree multi-output Random Forest with a seeded
80/20 train-test split (random_state=42). Its 12 predictors combine the ten
retained location, roof, directional sunlight, and yield variables with two
engineered terms: a directional sunlight sum and a south-to-north ratio. The
model evaluates annual sunlight total, carbon-offset potential, and total solar
capacity.

A separate Linear Regression script provides a simpler baseline for annual
sunlight total and carbon-offset potential. The Random Forest workflow reports
held-out RMSE, MAE, MAPE, and R², as well as five-fold shuffled R² for annual
generation. Both workflows can create diagnostic plots when run.

Interpreting the experiment
----------------------------
The study is best read as tract-level held-out reconstruction and estimation.
Directional sunlight inputs are substantively close to the annual-total outcome,
so strong fit would not by itself demonstrate independent, property-level
prediction. The current evaluation uses random rather than spatial or temporal
splits, and the repository does not retain source-version or license metadata for
the supplied file. These are important limits on any generalization claim.

Demonstration interface
-----------------------
The Streamlit application is a communication layer, not the study's central
model result. Its community view chooses the nearest available tract and displays
stored source values; it does not call Random Forest inference. Its homeowner view
uses a transparent, rule-based roof-area/yield calculation with optional
orientation, broad shading, and electricity-use inputs. Both views help users
interpret tract context but are not site-specific engineering estimates.

Repository map
--------------
- data/raw/: supplied Project Sunroof-style tract CSV
- data/processed/: ETL-derived clean CSV and SQLite table
- src/etl/pipeline.py: data preparation
- src/models/random_forest.py: primary Random Forest experiment and helpers
- src/models/linear_regression.py: Linear Regression baseline
- src/app/app.py: optional Streamlit research demonstration
- tests/test_random_forest_output.py: synthetic unit/regression coverage
- project-print/technical-blueprint.md: full technical research report

Reproduce the study
-------------------
1. Install dependencies: python -m pip install -r requirements.txt
2. Rebuild analytical data: python src/etl/pipeline.py
3. Run Random Forest evaluation: python src/models/random_forest.py
4. Run Linear Regression baseline: python src/models/linear_regression.py
5. Run tests: python -m pytest -q
6. Optionally launch the demo: python -m streamlit run src/app/app.py
